🔑 Maanmittauslaitoksen (MML) API-avain

Sovellus hakee kiinteistörajat ja kiinteistötunnukset automaattisesti ilman avainta suurimmissa kaupungeissa (mm. Turun seutu, Helsinki, Espoo, Oulu, Jyväskylä, Lahti) kuntien avoimista WFS-rajapinnoista sekä rakennukset OpenStreetMapista.

Jos haluat viralliset MML:n kiinteistörajat ja palstatunnukset kaikkiin Suomen kuntiin, voit syöttää tähän ilmaisen Maanmittauslaitoksen OGC API -avaimen. Avain tallennetaan vain oman selaimesi muistiin (localStorage).
