# Osoitetutka PRO – Chrome / Edge Selainlaajennus (Etuovi & Oikotie)

Lisää suoraan Etuovi.com- ja Oikotie.fi-asuntoilmoituksiin **"📡 Analysoi Osoitetutkassa"** -painikkeen, joka avaa kohteen osoitteen suoraan Osoitetutka PRO:ssa.

## Asennus (Chrome / Edge / Brave)
1. Avaa selaimessa `chrome://extensions` (tai `edge://extensions`).
2. Kytke oikeasta yläkulmasta päälle **Kehittäjätila (Developer mode)**.
3. Klikkaa **Lataa pakkaamaton (Load unpacked)** ja valitse tämä `extension`-kansio.
4. Avaa mikä tahansa asuntoilmoitus Etuovi.comissa tai Oikotie.fi:ssä — oikeaan alakulmaan ilmestyy painike **📡 Analysoi Osoitetutkassa**.
